## How to practise

1. Read the problem and the hint. Predict the output before you run anything.
2. Write your solution in a new `.py` file (do not edit the solutions folder).
3. Run it. If the result differs from your prediction, find out why before moving on.
4. Open the solution only after a real attempt, and compare the *behaviour*, not the wording.
5. Come back a week later and solve the problem again from a blank file.

## Notes

- All solutions are valid Python 3 and use only the standard library. They were run with Python 3.13 and the outputs shown are the real outputs.
- Part 6 problems are small *toy demos* of AI ideas (token estimates, similarity, retrieval, evaluation). They use no real AI service and need no keys. Anything resembling a key must stay in environment variables, never in code.
- The larger programs are in the [projects](../projects/README.md) folder.
